Quem é o Claude?

🧠
Modelo de Linguagem

🛡️
IA Constitucional
Guiado por princípios de honestidade, segurança e utilidade. Projetado para ser inofensivo e genuíno.

Assistente de Tarefas

Processa e lembra de 200 mil tokens numa conversa — equivale a um livro inteiro de contexto.

Extensível via MCP

Multi-Agente

GUI vs CLI

GUI
claude.ai

Interface gráfica acessada pelo navegador. Clique, arraste e converse.

  • Visual e intuitivo — zero configuração
  • Upload de arquivos, imagens e PDFs
  • Projetos com memória persistente
  • Artefatos renderizados ao vivo

Chat · Cowork · Code

💬
Chat
claude.ai/chat
Conversa direta e pontual. Cada sessão começa do zero — sem memória automática entre conversas.
✓ Perguntas e respostas rápidas
✓ Upload de arquivos por sessão
✓ Artefatos gerados ao vivo
✗ Sem memória entre sessões
✗ Sem contexto de projeto

✓ Arquivos e docs compartilhados
✓ Instruções customizadas fixas
✓ Contexto acumulado entre sessões
✓ Colaboração em equipe
Para quem: trabalho profissional diário
